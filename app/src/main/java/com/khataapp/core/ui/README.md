# `core.ui`

**Owns:** Material 3 theme with dynamic color, shared Compose components, Indian number formatting (₹1,00,000) for display only. Strings live in `res/values/` (English) and `res/values-hi/` (Hindi).

**Built in:** Phase 0 (theme, navigation shell), Phase 1 (formatting). See [`docs/DEVELOPMENT_PLAN.md`](../../../../../../../../docs/DEVELOPMENT_PLAN.md).

The plan moves this package into its own Gradle module (`:core:ui`) during Phase 0.
