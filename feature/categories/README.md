# `:feature:categories`

**Owns:** Categories (add, rename, recolor, icon, archive) and tags (create inline, rename, merge).

**Done in #17:** Categories screen (emoji icons from `CategoryIcons` in `:core:ui`, 16-colour palette, archive/unarchive, "use default name"; Uncategorized can't be archived) and Tags screen (usage counts, rename, merge, delete; renaming to a taken name offers a merge). The tag picker used while adding a transaction comes with the transaction screen (#18).

**Built in:** Phase 1. See [`docs/DEVELOPMENT_PLAN.md`](../../docs/DEVELOPMENT_PLAN.md).

**Module:** `:feature:categories` · package `com.openhand.khata.feature.categories` · Android library (`khata.android.library` + `khata.android.compose`).
